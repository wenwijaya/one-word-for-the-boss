One word for the boss: **Escalator**. A boss who escalates everything — every question, every decision, every tiny problem rides straight up to the next floor, and somehow the lift never comes back down with an answer.

## Run it

```sh
node main.ts
```

The program writes exactly one word to `/output/entry.txt` and exits 0.
